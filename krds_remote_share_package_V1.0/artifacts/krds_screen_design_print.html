KRDS 웹기획서 1. 프로젝트 개요

1. 프로젝트 개요

KRDS 사이트 전체 HTML을 하나의 웹기획 대상으로 보고, 정보구조와 화면군 요구사항을 재구성한다.

기획 목표공공 디지털 서비스 설계자가 KRDS 자료를 탐색, 이해, 적용, 검수할 수 있도록 화면 구조와 컴포넌트 요구사항을 문서화한다.
역기획 범위메인, 시작하기, 디자인 스타일, 컴포넌트, 기본 패턴, 서비스 패턴, 소식·소통, KRDS 소개 영역의 공개 HTML 전체.
핵심 사용자디자이너, 개발자, 정부 관계자, 서비스 운영자, 접근성/품질 검수 담당자.
주의사항공개 HTML 기반 추정 문서이며 실제 내부 운영 정책, 일정, 승인 체계는 별도 확인이 필요하다.
